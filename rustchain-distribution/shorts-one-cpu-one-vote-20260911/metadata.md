## Description
RustChain’s Proof of Antiquity separates consensus participation from raw compute speed: each verified physical machine gets one participation slot, then reward weight reflects the hardware class/antiquity rules. The current public docs list PowerPC G4 at 2.5× and modern x86_64 at 0.8×, while six fingerprint/anti-emulation checks are used to distinguish real hardware from VMs and emulators.

Source and miner docs: https://github.com/Scottcjn/Rustchain

Educational explainer only. No profitability or price claim.
