# RustChain Shorts Kit — One CPU, One Vote

Original Type C distribution package prepared for RustChain bounty #16601.

**Author credit:** @Cesar9712  
**Format:** vertical short, target runtime 45–55 seconds  
**Core idea:** explain that RustChain separates *participation* from *raw speed*: each verified physical machine gets a consensus slot, while antiquity affects reward weight. Modern x86_64 is intentionally weighted below vintage PowerPC tiers, and VM/emulator detection prevents simply faking old hardware.

Files:
- `script.md` — narration script under 60 seconds
- `capture.md` — exact 9:16 visual/edit instructions
- `metadata.md` — titles, description, tags, caption
- `SOURCES.md` — source map for every technical claim

This package avoids price promises and fabricated benchmarks. All technical claims trace to current public RustChain documentation.
