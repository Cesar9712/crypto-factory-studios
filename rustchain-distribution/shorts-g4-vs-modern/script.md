# Short script — A 2003-era G4 can outweigh a modern x86 on RustChain

**Target runtime:** 42–50 seconds
**Format:** 9:16 vertical

## Hook
What if an old PowerPC G4 could carry more consensus weight than a modern PC?

## Narration
RustChain uses Proof of Antiquity: one physical CPU gets one vote, then verified hardware age changes the vote weight.

On the current RustChain multiplier table, a PowerPC G4 starts at **2.50×**, while modern x86_64 starts at **0.80×**. That is **3.125 times the base weight** before tenure growth.

The network does not just trust a model name. It uses hardware fingerprint and anti-emulation checks, and detected virtual machines are reduced to near-zero reward weight.

To inspect it yourself, start with:

`pip install clawrtc`

Old hardware is not automatically useless here — its age is the resource being measured.
