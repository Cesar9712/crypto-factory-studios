## Short description
RustChain uses Proof of Antiquity: one physical CPU gets one vote, with verified hardware age affecting consensus/reward weight. The current table lists PowerPC G4 at 2.50× and modern x86_64 at 0.80×, while anti-emulation checks heavily penalize detected VMs.
