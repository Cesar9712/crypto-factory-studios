FAQ

Indie game hosting questions

Can I start without paying?

Yes. Creator Free is intended for trying the publishing workflow before choosing higher platform limits.

What type of games fit best?

Browser-ready indie games, including HTML5 projects and compatible Godot Web exports, are the clearest fit for the current creator workflow.

Do I need Web3?

No. Web3 is optional; a normal browser game can use the creator platform without blockchain features.
