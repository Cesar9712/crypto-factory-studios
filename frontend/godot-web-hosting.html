WHY CFS

Designed for small Web game creators

Instead of combining a separate static host, user system, publishing dashboard and game catalog, Crypto Factory Studios aims to keep the creator workflow together. The Free tier lets developers test the workflow before moving to higher platform limits.

Does this require blockchain?

No. You can publish a normal Godot Web game. Web3 features are optional rather than a requirement for using the creator platform.

Can players install nothing?

Published Web builds are intended to run through the browser, subject to the capabilities and compatibility of each game export.
