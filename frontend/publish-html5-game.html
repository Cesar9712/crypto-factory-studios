FAQ

HTML5 game hosting questions

Can I publish a browser game without running my own server?

That is the goal of Crypto Factory Studios: give creators a managed place to upload and publish Web game builds instead of assembling the entire publishing stack themselves.

Is there a free plan?

Yes. Creator Free is designed for testing ideas and publishing initial games before upgrading to higher limits.

Does Crypto Factory Studios support HTML5?

Yes. The creator workflow is built around browser-ready Web builds packaged for upload.

Is Web3 required?

No. Web3 is an optional capability of the broader platform; creators can use Crypto Factory Studios simply to publish browser games.
